What You’ll Learn Today

This workshop introduces you to Claude Code CLI, Anthropic’s official AI coding assistant approved for productive use at SAP. You’ll learn how to set up the core tools and optionally extend them with MCP (Model Context Protocol) servers for SAP-specific integrations.

Key Concepts

Claude Code CLI: A command-line AI assistant for conversational software development - Approved for productive use at SAP with Hyperspace LLM Proxy - Works with your files and folders - Understands context and can make code changes

MCP (Model Context Protocol): Open standard for connecting AI assistants to data sources - Think of it as “plugins” for AI coding assistants - Extends Claude’s capabilities with SAP system access - Optional but powerful additions

Part 1: Core Setup (Required for Everyone)

Prerequisites for Core Setup

  • Windows laptop with admin rights
  • SAP network access
  • Node.js installed (v18+) - Check with: node --version
  • Text editor (VS Code, Notepad++, etc.)

Step 1: Install Hyperspace LLM Proxy

The Hyperspace LLM Proxy provides LLM access for Claude Code at SAP.

Installation

  1. Visit: https://pages.github.tools.sap/hAIperspace/hai-docs/

  2. Follow installation instructions for hai CLI

  3. Verify installation:

    hai --version

Configure Claude Code

  1. Find the specific guide: https://pages.github.tools.sap/hAIperspace/hai-docs/llm-proxy/recipes/claude/

  2. Follow configuration steps to edit ~/.claude.json

  3. Test the proxy:

    # Terminal 1: Start proxy
hai proxy start

# Terminal 2: Launch Claude Code
claude

✅ Checkpoint: You should see Claude Code start successfully and respond to basic questions.

Step 2: Your First Claude Code Interaction

Starting Claude Code

# Navigate to your project folder
cd C:\path\to\your\project

# Start Claude Code
claude

Try These Commands

# In Claude Code session:
What version of Node.js am I running?
List the files in the current directory
Show me the README file

Exiting Claude Code

  • Type: exit
  • Or press: Ctrl+C

✅ Checkpoint: Claude Code responds to your queries and can read files.

Part 2: Optional MCP Server Setup

Choose one or more MCP servers to extend Claude’s capabilities. You can add more later!

Option A: mcp-abap-adt (ABAP Development Tools)

What it does: Allows Claude to read ABAP code, run tests, check transports, and more.

Prerequisites for this MCP server: - Git installed - Node.js (v18+) installed - SAP system access with ADT enabled - SAP system credentials (username/password for dev/test systems)

Setup Steps

  1. Clone and build (one-time setup):

    cd C:\Users\<username>\SAPDevelop
git clone https://github.tools.sap/<username>/mcp-abap-adt.git
cd mcp-abap-adt
npm install
npm run build

  2. Configure SAP connection: Create .env file in mcp-abap-adt folder:

    SAP_URL=https://your-sap-system.com:8000
SAP_CLIENT=100
SAP_USERNAME=your_username
SAP_PASSWORD=your_password

    ⚠️ Important: Keep this file secure, never commit to Git!

  3. Add to Claude Code config: Edit ~/.claude.json (Windows: C:\Users\<username>\.claude.json):

    {
  "mcpServers": {
    "mcp-abap-adt": {
      "command": "cmd",
      "args": ["/c", "node", "C:\\Users\\<username>\\SAPDevelop\\mcp-abap-adt\\dist\\index.js"],
      "type": "stdio"
    }
  }
}

    Important Notes:

    • Use double backslashes (\\) in the path or forward slashes (/)
    • Replace <username> with your actual Windows username

  4. Restart Claude Code to load the MCP server

Testing

Try these prompts in Claude Code:

Search for ABAP objects starting with Z*
Show me class ZCL_YOUR_CLASS
Get the transport history for ZCL_YOUR_CLASS

✅ Checkpoint: Claude can access your SAP system and retrieve ABAP code.

Option B: mcp-wiki (SAP Wiki Search)

What it does: Searches and retrieves content from SAP’s internal Wiki.

Prerequisites for this MCP server: - Git installed - Bun runtime installed (https://bun.sh/) - Access to SAP Wiki (wiki.one.int.sap)

Setup Steps

  1. Clone the repository:

    cd C:\Users\<username>\SAPDevelop
git clone https://github.tools.sap/claude/mcp-wiki.git
cd mcp-wiki

  2. Add to Claude Code config: Edit ~/.claude.json:

    {
  "mcpServers": {
    "mcp-wiki": {
      "command": "bun",
      "args": ["C:/Users/<username>/SAPDevelop/mcp-wiki/src/index.ts"],
      "env": {
        "WIKI_DOMAIN": "wiki.one.int.sap"
      },
      "type": "stdio"
    }
  }
}

    Important Notes:

    • Replace <username> with your actual Windows username
    • Use forward slashes (/) in the path
    • Make sure you have Bun installed: bun --version

  3. Restart Claude Code

Testing

Search SAP Wiki for "ABAP Cloud best practices"
Find wiki pages about RAP development

✅ Checkpoint: Claude can search and retrieve Wiki content.

Combining Multiple MCP Servers

You can use both MCP servers together! Here’s the complete config:

~/.claude.json:

{
  "mcpServers": {
    "mcp-abap-adt": {
      "command": "cmd",
      "args": ["/c", "node", "C:\\Users\\<username>\\SAPDevelop\\mcp-abap-adt\\dist\\index.js"],
      "type": "stdio"
    },
    "mcp-wiki": {
      "command": "bun",
      "args": ["C:/Users/<username>/SAPDevelop/mcp-wiki/src/index.ts"],
      "env": {
        "WIKI_DOMAIN": "wiki.one.int.sap"
      },
      "type": "stdio"
    }
  }
}

Note: Replace <username> with your actual Windows username in all paths.

Troubleshooting

Common Issues

1. “hai command not found”

  • Solution: Reinstall hai CLI, check PATH environment variable

2. Claude Code doesn’t start

  • Check: claude --version works
  • Check: ~/.claude.json has valid JSON syntax (use https://jsonlint.com/)
  • Try: Comment out MCP servers temporarily to isolate issue

3. MCP server not loading

  • Check: Absolute paths in config (not relative paths like ./ or ../)
  • For mcp-abap-adt: Run npm run build again in project folder
  • Check: Windows username is correct in paths

4. SAP connection fails (mcp-abap-adt)

  • Check: .env file exists in mcp-abap-adt folder
  • Check: SAP_URL, SAP_CLIENT, credentials are correct
  • Check: SAP system is accessible (try in browser)
  • Check: ADT services active (transaction SICF, path /sap/bc/adt)

5. “hai proxy not running”

  • Solution:

    hai proxy start
# Keep this terminal open
# Open new terminal for Claude Code
claude

Best Practices

Security

  • ✅ Use .env files for credentials (never commit to Git)
  • ✅ Keep ~/.claude.json secure
  • ✅ Use Basic Auth for dev/test, SSO for production systems
  • ❌ Don’t share credentials in chat or commits

Workflow

  1. Start hai proxy start (keep running)
  2. Open new terminal
  3. Navigate to project: cd /path/to/project
  4. Start Claude: claude
  5. Work with AI assistant

Effective Prompts

  • Be specific: “Show me class ZCL_MY_CLASS” vs “Show me code”
  • Ask for context: “Explain what this class does”
  • Request actions: “Run unit tests for this class”
  • Iterate: Build on previous responses, ask follow-up questions

Recommended Additional Software

While not required for the workshop, these tools can enhance your development workflow with Claude Code:

Pandoc (Document Converter)

What it does: Universal document converter supporting markdown, HTML, PDF, and many other formats.

Use cases: - Convert markdown documentation to HTML or PDF - Generate formatted reports from markdown files - Create presentation slides from markdown - Convert between different markup formats

Installation: - Download from: https://pandoc.org/installing.html - Windows: Use installer or winget install pandoc - Verify: pandoc --version

Example usage:

# Convert markdown to HTML
pandoc document.md -o document.html

# Convert markdown to PDF (requires LaTeX)
pandoc document.md -o document.pdf

# Convert with styling
pandoc document.md -s -o document.html --metadata title="My Document"

Other Useful Tools

  • Git GUI clients: GitHub Desktop, GitKraken, or SourceTree for visual Git operations
  • Markdown editors: Typora, MarkText, or VS Code with markdown extensions
  • Terminal multiplexers: Windows Terminal with multiple tabs for managing hai proxy + Claude sessions
  • JSON validators: Online tools like jsonlint.com for validating .claude.json configuration
